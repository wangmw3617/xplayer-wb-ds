## XPlayer 打包策略最终定为「按 ABI 分包发布」（用户明确要求，否决 R8）

- 用户决策演变：先否掉 R8；再否决「单个通用大包」，要求像多数安卓项目一样，**发布页提供多种架构选择** → 最终方案 = ABI 分包 + 额外一个 universal 兜底包。
- 实施：`app/build.gradle.kts` 中 `splits.abi { isEnable = true; include("armeabi-v7a","arm64-v8a","x86","x86_64"); isUniversalApk = true }`；`versionCode=4 / versionName=1.2.0`。
- 前提已核实：`mpv-android-lib-android:0.2.2` 与 `org.jellyfin.media3:media3-ffmpeg-decoder:1.9.0+1` 两个 AAR 的 `jni/` 下都自带四套 `.so`（各 13 个），分包不会出现缺库。
- Keep 的压缩项：`packaging.jniLibs.useLegacyPackaging = true`、`packaging.dex.useLegacyPackaging = true`。
- 实测 release 体积：arm64-v8a 35.5MB / armeabi-v7a 34.2MB / x86 36.6MB / x86_64 37.0MB / universal 93.9MB；debug 对应 40.8–105.5MB。单包构成：原生库 40–53MB 原始 → 17–20MB，dex 33.4MB → 12.0MB，assets（subfont.ttf）6.3MB → 2.9MB。
- 分包后各 ABI 的 `versionCode` 相同（AGP 未加 ABI 偏移），GitHub 分发无影响；上 Play 多 APK 才需要偏移。
- CI 重写：`Build multi-ABI APKs` job，循环把 `app/build/outputs/apk/<type>/*.apk` 重命名为 `XPlayer-<abi>-<type>.apk` 统一放 `dist/`，逐个打印 `apksigner --print-certs` 与 `aapt2 dump badging | grep native-code`；artifact 改为 `XPlayer-debug-apks` / `XPlayer-release-apks`（多文件）；Release body 内置选包对照表。
- 发布：tag `v1.2.0`，Release <https://github.com/wangmw3617/xplayer-wb-ds/releases/tag/v1.2.0>，附件 10 个（4 ABI + universal，release 与 debug 各一轮），全部 `CN=XPlayer` 正式证书；tag 构建 7m39s 全绿。
- 签名密钥：`C:\Users\wang\.xplayer-keys\xplayer-release.jks`（口令在同目录 credentials.txt）。v1.0.0 是 debug 证书签的，跨版本升级需先卸载。

## 外部「打开方式」+ 媒体信息（v1.4.0 候选功能，未升版本）

- `MediaSource` 新增 `ContentUriSource`（SAF/第三方 provider）。`MediaUriResolver` 把 content:// 尽量反解成真实路径：优先查 `_data`，其次 `com.android.externalstorage.documents`（primary:… / 卷 ID:…）、下载 provider 的 `raw:`、媒体库 `video:123`/`audio:123`；反解成功 → `LocalFileSource`（可 mpv、可连播、可读外挂字幕、可落库），失败 → `ContentUriSource`（仅 Media3）。
- Manifest：MainActivity 增加 3 个 `ACTION_VIEW` 过滤器（`video/*`、`audio/*`、octet-stream + 29 条扩展名 pathPattern，XML 里写 `\\.`、aapt 会还原成 `\.`）。
- 传递方式：Activity 用 `MutableStateFlow<Uri?>` 而非 Compose State（消费时置空不会取消处理协程），NavHost 里 `filterNotNull().collectLatest` 解析后跳 `player?type=uri`；已停在播放页时先 pop 再跳，防止旧内核继续出声。
- `EngineRouter` 对 `ContentUriSource` 固定 MEDIA3（`EngineReason.EXTERNAL_URI`）；`PlayerController` 拒绝切 mpv、跳过落库、解码失败不再回退 mpv；播放设置里该来源的 mpv 行置灰（`mpvBlockedByUri`）。
- 播放页 `PlayerViewModel` 暴露 `sourceKind/sourceKey/sourceTitle`，播放设置「画面」分组新增「媒体信息」入口；视频详情面板标题右侧加 ⓘ 按钮。
- `data/media/MediaInfoProbe`：MediaExtractor 逐轨读取（mime/codec string/profile+level/分辨率/帧率/码率/色彩标准·传输·范围/rotation/声道/采样率/语言/默认），content:// 走 `openAssetFileDescriptor`，长度未知时退回整 fd；网络流只给基础信息。
- `ui/media/MediaInfoScreen`：文件 / 封装 / 逐轨分组卡片 + 4K·HDR·编码徽章，纯音频文件同样适用。
- 验证：compileDebugKotlin / assembleDebug / lintDebug 全绿（0 error）；本机无 AVD，UI 与 SAF 行为需真机验收。
