# 2026-11-24

## XPlayer 打包策略最终定为「通用单包」（用户明确要求，否决 R8）

- 用户决策：**不开 R8**，也不做 ABI 分包；像多数安卓项目一样出一个包含 `armeabi-v7a / arm64-v8a / x86 / x86_64` 的通用 APK。
- 实施：`app/build.gradle.kts` 中 `splits.abi.isEnable = false`，改由 `defaultConfig.ndk.abiFilters` 显式列四个 ABI；`versionCode=3 / versionName=1.1.0`。
- 前提已核实：`mpv-android-lib-android:0.2.2` 与 `org.jellyfin.media3:media3-ffmpeg-decoder:1.9.0+1` 两个 AAR 的 `jni/` 下都自带四套 `.so`（各 13 个），通用包不会出现某架构缺库崩溃。
- Keep 的压缩项：`packaging.jniLibs.useLegacyPackaging = true`、`packaging.dex.useLegacyPackaging = true`（体积优先，代价是安装时解压）。
- 实测体积：release **93.9MB** / debug **105.5MB**。构成：原生库 188.9MB 原始 → 77.4MB（arm64 46.8 / x86_64 53.0 / x86 49.0 / v7a 39.9），dex 33.4MB → 12.0MB，assets（subfont.ttf）6.3MB → 2.9MB。
- 单架构回退方式（~36MB）：`abiFilters = listOf("arm64-v8a")` 或打开 `splits.abi`；已写入 README。
- CI 同步：job 改名 `Build universal APK`，产物更名 `XPlayer-universal-debug.apk` / `XPlayer-universal-release.apk`，release step 增加 `aapt2 dump badging | grep native-code` 与 `apksigner --print-certs` 输出，便于每次构建自证四架构与签名。
- 发布：tag `v1.1.0`，Release <https://github.com/wangmw3617/xplayer-wb-ds/releases/tag/v1.1.0>，release 93.9MB（正式证书 CN=XPlayer）+ debug 105.47MB；tag 与 main 两次 CI 均 success（tag 运行 4m33s）。
